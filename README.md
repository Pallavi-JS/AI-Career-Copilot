# AI Career Copilot 🤖

AI-powered resume analysis and job matching system built using Python and Streamlit.

## Features

- Resume PDF Upload
- Skill Extraction
- ATS Score Calculation
- Recommended Career Roles
- Job Matching
- Skill Gap Analysis
- Interview Question Generation

## Tech Stack

- Python
- Streamlit
- NLP
- Scikit-Learn
- Sentence Transformers
- GitHub
